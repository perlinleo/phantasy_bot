# Support

- Use GitHub Issues for reproducible bugs and feature proposals.
- Use GitHub Discussions, if enabled, for usage questions and design discussion.
- Use [SECURITY.md](SECURITY.md) for vulnerabilities; never post sensitive material publicly.

Before asking for help, include the application version, operating system, Python/Blender/FFmpeg
version where relevant, and sanitized logs. Do not include tokens, user media, SQLite databases,
or private Telegram identifiers.
